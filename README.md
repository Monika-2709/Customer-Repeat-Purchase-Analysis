# Customer Repeat Purchase Analysis

## 📊 Overview
Customer Repeat Purchase Analysis project focused on measuring customer loyalty and identifying repeat-customer segments.

## 🎯 Objectives
- Calculate repeat customer rate
- Compare first-time vs repeat customer AOV
- Segment customers based on purchase frequency
- Generate actionable business insights

## 🛠️ Tools
- Python
- Pandas
- NumPy
- SQL

## 📌 Results
- 2,500 customers analyzed
- 51.96% repeat customer rate
- Customers segmented into:
  - One-time
  - Repeat (2–3 orders)
  - Loyal (4+ orders)

## 📂 Files
- `orders.csv`
- `customer_segments.csv`
- `segment_table.csv`
- `category_summary.csv`
- `analysis.py`
- `analysis.sql`
- `Customer_Repeat_Purchase_Analysis_Report.pdf`

## 💡 Key Insight
Repeat purchase analysis helps identify loyal customers and provides opportunities for targeted retention and second-purchase campaigns.
